# ❄️ نَفَس نقي - شركة تنظيف وغسيل مكيفات بجدة

موقع لاندينج بيج (Landing Page) إعلاني متكامل، سريع، ومتوافق مع إعلانات جوجل (Google Ads) ومحسن لمحركات البحث (Local SEO) لشركة **نَفَس نقي** المتخصصة في غسيل وصيانة مكيفات السبليت والمركزي بمدينة جدة.

---

## 🌟 مميزات المشروع

- ⚡ **أداء فائق وسرعة تحميل:** مبني بـ HTML5 / Vanilla CSS / Vanilla JS بدون مكتبات ثقيلة لضمان أعلى نقاط Quality Score في Google Ads.
- 📱 **تصميم متجاوب بالكامل (Mobile First):** متوافق بدقة مع جميع شاشات الهواتف والأجهزة اللوحية والمكتبية.
- 📞 **تحويل مباشر (Conversion Optimized):**
  - أزرار اتصال سريع ورابط واتساب مباشر مع رسائل جاهزة.
  - شريط تحويل عائم وسفلي مخصص لمستخدمي الموبايل.
  - عداد تنازلي لحث العميل على الحجز الفوري (Urgency & Scarcity).
- 💳 **وسائل الدفع السعودية:** استعراض بوابات الدفع المعتمدة (مدى، فيزا، ماستركارد، أبل باي، STC Pay، تمارا، تابي، الدفع عند الاستلام).
- 🔍 **سيو وبيانات منظمة (Schema.org / JSON-LD):** دعم كامل لـ `HVACBusiness` و `FAQPage` لتحسين الظهور في نتائج البحث المحلية.

## 🚀 تشغيل ومعاينة الموقع

يمكنك فتح ملف `index.html` مباشرة في أي متصفح، أو تشغيل الموقع عبر خادم محلي مثل:
```bash
# باستخدام Live Server في VS Code أو عبر:
npx serve .
```

## 🌐 النشر على GitHub Pages

لتفعيل المعاينة الحية للموقع مباشرة عبر GitHub:
1. توجه إلى إعدادات المستودع **Settings** في GitHub.
2. اختر من القائمة الجانبية **Pages**.
3. تحت **Branch**، اختر `main` واضغط **Save**.
4. سيصبح رابط الموقع المباشر:
   `https://7ossamabdelmonem20-jpg.github.io/osama/`
